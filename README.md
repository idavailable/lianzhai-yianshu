# 莲斋医意立斋案疏 · 医案数据库

《莲斋医意立斋案疏》（精简版）医案数字化项目：明·薛己（立斋）医案二百五十七则，清·叶崧逐案作疏，按三十四门编排，附叶桂（天士）、陈士铎（远公）、傅山（青主）对同类病症的治法对照。

## 功能

- **全文检索**：医案原文、崧疏、脚注一并检索，关键词高亮
- **门类筛选**：按原书三十四门（正编二十门 + 补遗十四门）浏览
- **方剂索引**：按常用方剂（六味地黄丸、补中益气汤、八味丸……）反查医案
- **转归筛选**：痊愈向安 / 殁与不治
- **医案详情**：原文（含校按、脚注悬浮注释）+ 崧疏全文，前后案翻页
- **名家对照**：十四个病症主题下，薛立斋与叶桂、陈士铎、傅青主治法思路对照，引文标注门类出处

## 使用

直接打开 `index.html` 即可（数据内嵌于 `data/data.js`，无需服务器）。亦可部署至 GitHub Pages。

## 数据说明

| 文件 | 内容 |
|------|------|
| `data/cases.json` | 257 案结构化数据：案号、门类、编次、患者、原文、崧疏、校按、脚注、方药、转归 |
| `data/masters.json` | 名家治法对照（14 个病症主题 × 4 家） |
| `data/data.js` | 上述数据的 JS 封装（页面直接引用） |
| `scripts/parse.py` | 文本解析脚本：由原始 txt 生成 `cases.json` |

## 学术说明

- 原文以精简版电子文本为据，校按、脚注悉仍其旧
- 方药字段由程序自动提取，仅供检索辅助，方名异同（如「六味丸」归并于「六味地黄丸」）以正文为准
- 名家对照部分的引文均标注出处（如《临证指南医案·中风》华岫云按、《辨证录·中风门》、《傅青主男科·虚劳门》）

仅供中医文献研究之用。
